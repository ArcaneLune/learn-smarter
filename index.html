如何高效学习

按顺序照着做：定目标、找弱点、专注学、合书回想、隔天复习、专练弱点，再用项目检验。

第 1 章

学之前：先定目标、找缺口

3 / 3 条

先回答两个问题：学完后你要会做什么？你现在还差在哪？答案越清楚，越不会把时间浪费在已经会的内容上。

1

先写清楚：学完后我要会做什么

#
核心动作今天就做明确结果
说人话

不要把目标写成“看完一本书”或“理解数据分析”。要写成一个看得见的结果，例如：“我能独立整理一份数据，并用三张图讲清结论。”

照着做

  1. 写下学完后要完成的任务，而不是要看完多少资料。
  2. 加上截止时间和最低要求。
  3. 把它缩小成一周内能完成、能检查的结果。

做到什么算完成

目标里必须有三个东西：你要做的动作、做出的成果、判断好坏的标准。

例子

不要写“掌握摄影”，可以写：“本周日之前，独立拍摄并选出 10 张曝光正确的人像照片。”

来源定位《学习之道》合集 TXT，第 4799–4805、4867 行（有目的的练习）
2

学习前先试一次，找出真正不会的地方

#
核心动作今天就做先试一次
说人话

别急着从第一页开始看。先不看资料做几道题，或者直接试着完成任务，你会马上知道自己该重点学什么。

照着做

  1. 不看资料，写下你已经知道的内容。
  2. 做 5 道典型题，或直接试做一个最小任务。
  3. 把结果分成“会、半会、不会”三类。
  4. 先挑一个最重要的“不会”开始学。

做到什么算完成

你已经明确写出：“我下一轮要解决的具体问题是______。”

注意

第一次做得差很正常。这次尝试不是考试，只是帮你找到起点。

来源定位《认知天性》PDF，第 38–49、163 页（测验效应与动态测验）
3

太难就拆小，太简单就加难

#
进阶动作每周调整难度
说人话

最合适的练习，是你大部分能做，但还会犯一点错。完全不会就拆小，几乎全对就加一点难度。

照着做

  1. 完全不会：先看一个示范，再只练其中一步。
  2. 能做但常错：保持当前难度，找出最常错的位置。
  3. 几乎全对：减少提示、限时完成，或者换一道变式题。

做到什么算合适

你能独立完成大部分步骤，同时每轮还能发现一两个具体问题。

注意

难度不是越高越好。难到只能猜时，先补基础比硬撑更有效。

来源定位《学习之道》合集 TXT，第 4815、4821–4843 行；《认知天性》PDF，第 110 页
第 2 章

开始学习：先专注，再休息

3 / 3 条

不等状态，不靠硬撑。先专注一小段时间，再短暂离开，让大脑在认真思考和放松整理之间来回切换。

1

先专注 25 分钟，只做一件事

#
核心动作今天就做25 分钟
说人话

不要逼自己“一口气学完”。只答应自己：接下来 25 分钟，认真做一件具体的事。

照着做

  1. 写下这一轮唯一任务，例如“闭卷做第 1～3 题”。
  2. 把手机放远，关掉通知，计时 25 分钟。
  3. 想起其他事情时，只记在纸上，先不处理。
  4. 时间到就休息 5 分钟，再决定是否继续。

做到什么算完成

25 分钟里，你没有主动切换到其他任务。题目没全部做完也没关系。

注意

这就是常见的番茄计时法。如果 25 分钟仍然难开始，先做 10 分钟。

来源定位《学习之道》合集 TXT，第 1677–1705 行（番茄工作法）
2

把手机和其他干扰移开

#
核心动作每日清除干扰
说人话

分心不一定是你意志力差，可能只是干扰离得太近。先整理环境，再开始学习。

照着做

  1. 把手机放进另一个房间，或至少放到够不着的地方。
  2. 关闭通知和无关网页，只留下本轮需要的资料。
  3. 固定开始动作：坐下、写任务、开计时。
  4. 前一天准备好第二天第一轮要用的材料。

做到什么算完成

坐下后不需要再找资料、整理桌面或决定先做什么，可以直接开始。

注意

目标不是创造绝对安静，而是让分心比继续学习更麻烦。

来源定位《学习之道》合集 TXT，第 1607、1655–1667、1695 行（拖延信号与过程关注）
3

卡住时先离开一会儿，再回来

#
进阶动作每日专注＋休息
说人话

认真想过仍然没有思路，就先停下来。散步、洗澡或睡一觉后再回来，常常会看到新的解法。

照着做

  1. 先独立尝试约 20 分钟，写清楚卡在哪一步。
  2. 离开屏幕，散步或做简单家务，不继续刷相关内容。
  3. 回来后先写下新思路，再查看答案。

做到什么算完成

你回来后至少尝试了一条新路径，或者能更准确地说明自己哪里不懂。

注意

休息只在认真尝试之后有效。还没开始就离开，只是在拖延。

来源定位《学习之道》合集 TXT，第 453、459–507 行（专注模式与发散模式）
第 3 章

学完马上回想，不要只重读

3 / 3 条

看着资料觉得熟，不等于你能自己说出来。每学完一小段就合上资料回想，再检查和改错。

1

学完一小段，马上合上资料回想

#
核心动作今天就做合书回想
说人话

看完一小段后，立刻合上资料，用自己的话写出刚才学了什么。想不起来并不是失败，而是在告诉你哪里需要再学。

照着做

  1. 学习 10～20 分钟后，合上书或切走页面。
  2. 写出三个要点，再举一个自己的例子。
  3. 打开资料，用另一种颜色补上遗漏和错误。

做到什么算完成

你在看答案前，已经独立写出一份回忆。直接抄资料不算。

注意

回想时越费力，越能暴露真实掌握程度。先努力想，再核对。

来源定位《认知天性》PDF，第 38–49 页；《学习之道》合集 TXT，第 1095–1105 行
2

把笔记改成下一次要回答的问题

#
核心动作每日自测题
说人话

不要只抄答案。把每个重点改写成问题，下一次复习时先回答，再看笔记。

照着做

  1. 每个小节写 1～3 个问题，优先问“为什么、怎么做、什么时候用”。
  2. 把答案折叠、遮住，或放到卡片背面。
  3. 第二天随机抽题，先口述或写答案，再核对。
  4. 答错的题安排下一次复习。

示例

不要记“间隔复习的定义”，改问：“为什么隔几天再复习更容易记住？我准备什么时候复习？”

做到什么算完成

只看问题时，你能用自己的话回答，而不是只认得答案。

来源定位《认知天性》PDF，第 49、55、228–230 页（费力检索与自测）
3

错题只记三件事：错在哪、为什么、怎么改

#
进阶动作每日记录错因
说人话

错题本不是题目收藏夹。真正有用的是：你在哪一步错了、为什么会错、下次准备怎么做。

照着记

要记什么 写什么
错在哪 具体错在第几步
为什么 不懂概念、认错题型，还是粗心执行
怎么改 下次看到什么线索，就采取什么动作

做到什么算完成

记录完后，立刻做一道相似但不完全相同的题，并且做对。

注意

不要把正确答案整段抄下来。你需要保存的是“改错规则”，不是更多资料。

来源定位《学习之道》合集 TXT，第 1105、4815 行；第 9150 行（反馈与模型纠错）
第 4 章

隔开时间复习，混合不同题型

3 / 3 条

同一天重复很多遍，只会让你暂时觉得熟。隔几天再回想，并把容易混淆的题型放在一起练，记得更久，也更会选方法。

1

当天回想，再在第 1、3、7、14 天复习

#
核心动作今天就做隔天复习
说人话

不要在同一天把同一内容看很多遍。等到有一点忘记时再回想，反而更容易记得久。

照着做

  1. 学完当天，合上资料回想一次。
  2. 先在第 1、3、7、14 天各复习一次。
  3. 每次都先回答问题，再看答案。
  4. 已经很熟的内容延后复习；经常答错的内容提前复习。

做到什么算完成

每个重点都有下一次复习日期，而且复习时不是直接重读。

注意

1—3—7—14 只是方便开始的参考安排，不是固定公式。请根据答题表现调整。

来源定位《认知天性》PDF，第 60、75、95 页（间隔练习与再巩固）
2

不要连续刷同一种题

#
核心动作每日混合题型
说人话

把几种容易混淆的题型打乱练。这样你不但会做，还能学会判断“这道题该用什么方法”。

照着做

  1. 选 2～4 种相近但不同的题型。
  2. 打乱顺序，并去掉题型提示。
  3. 每道题先写一句：“我选择这个方法，因为______。”
  4. 做完后比较：这些题最关键的区别是什么？

做到什么算完成

看到一道新题时，你能先判断题型和方法，再开始计算或作答。

注意

混合练习一开始会更慢、更容易错，这是正常的。你练的是判断，不只是手熟。

来源定位《认知天性》PDF，第 61、65–66、76、97 页（穿插练习）
3

换个场景再用一次

#
进阶动作每周换个场景
说人话

题目换一种说法、数据或场景后，你仍然会用，才说明你学到的是方法，而不是记住了答案。

照着做

  1. 给原题换一组数据或一个生活场景。
  2. 加入一两条无关信息，练习找关键线索。
  3. 再找一个不适用这个方法的反例。
  4. 向别人解释：为什么这里可以用，那里不能用。

做到什么算完成

你能在一个没见过的场景中正确使用方法，并说清它和原题哪里相同。

来源定位《认知天性》PDF，第 57–73、97 页（多样化练习与辨析）
第 5 章

把零散知识连成一张网

3 / 3 条

不要孤立地背知识点。把它们压缩成小卡、用熟悉的例子解释，再画出彼此关系，使用时才能快速想起来。

1

把一个知识点压缩成一张小卡

#
核心动作每日知识小卡
说人话

把零散内容整理成一张小卡：它解决什么问题、什么时候用、具体怎么做。需要时就能快速想起来。

照着做

  1. 用一句话写：这个知识能解决什么问题？
  2. 写出三个“看到这些情况就该想到它”的线索。
  3. 写下最少操作步骤。
  4. 补一个不能使用它的反例。

做到什么算完成

不看资料时，你能在一分钟内讲清楚这张卡，并用它解决一道新题。

注意

一张卡只讲一个核心方法。塞得太多，就无法快速调用。

来源定位《学习之道》合集 TXT，第 991–1323 行（组块构建与能力错觉）
2

用熟悉的事物解释抽象概念

#
进阶动作今天就做通俗解释
说人话

如果一个概念很抽象，就把它比作熟悉的东西。同时说明两者哪里不同，避免越解释越错。

照着做

  1. 先找出概念最重要的关系。
  2. 找一个有相似关系的日常事物。
  3. 写出两个相似点和一个不同点。
  4. 用这个例子向一个不了解主题的人解释。

示例

可以把工作记忆比作一张小桌子：一次放太多东西就会乱。但大脑并不是真正的桌子，这只是帮助理解容量有限。

做到什么算完成

对方听完后，能用自己的话复述概念，而且没有把类比当成事实。

来源定位《学习之道》合集 TXT，第 7519、7645、7727 行（比喻法与拓展）
3

画出关系图，再用它做一次预测

#
核心动作每周关系图
说人话

把重要因素和它们的关系画出来。然后改变一个条件，先猜结果，再用例子检查自己猜得对不对。

照着做

  1. 写下最重要的人、步骤或条件。
  2. 用箭头标出谁影响谁、谁先谁后。
  3. 改变其中一个条件，先写下你预测的结果。
  4. 找实际案例检查；猜错时修改关系图。

做到什么算完成

这张图既能解释一个已经发生的例子，也能对一个新情况给出可以验证的预测。

来源定位《认知天性》PDF，第 95、146 页；《学习之道》合集 TXT，第 4209–4211 行
第 6 章

专门练不会的地方

3 / 3 条

重复已经会的内容，只会让动作更熟。真正的进步来自：每次挑一个弱点，练到稍微有点难，得到反馈后马上再试。

1

每次只练一个具体弱点

#
核心动作今天就做专练一项
说人话

不要笼统地“多练”。每次挑一个最具体的弱点，专门练 20～40 分钟，并记录结果。

照着做

  1. 从错题记录中挑一个最常出现的问题。
  2. 设计一轮只针对它的练习。
  3. 先写下成功标准，例如正确率、用时或连续成功次数。
  4. 结束后记录结果，决定下一轮继续、加难还是补基础。

示例

不要写“练演讲”，可以写：“不看提词，连续三次在 60 秒内讲清问题、证据和结论。”

做到什么算完成

你能用数据回答：这轮具体练了什么，比上一轮好在哪里？

来源定位《学习之道》合集 TXT，第 4769、4799–4805、4867 行（有目的的练习）
2

让练习比现在稍微难一点

#
核心动作每日稍微加难
说人话

练习要难到会犯一点错，但又能靠自己完成大部分。太简单没有进步，太难只会反复猜。

太简单时

  • 减少提示或参考资料。
  • 缩短完成时间，但不能降低基本质量。
  • 加入一种陌生变式。
  • 不只给答案，还要解释为什么这样做。

太难时

把任务拆小、先看一个示范、恢复部分提示，或者只练最薄弱的一步。

做到什么算合适

你能独立完成大部分，同时每轮都会暴露一个可以修正的新问题。

来源定位《学习之道》合集 TXT，第 4821–4843 行（走出舒适区）
3

得到反馈后，马上改一次再试

#
进阶动作每日改完再试
说人话

做完后尽快知道哪里错了，并马上用新方法再做一次。只看反馈、不重新尝试，通常改不掉错误。

照着做

  1. 先独立完成，保留草稿和思考过程。
  2. 对照答案、测试结果，或请老师、同伴评价。
  3. 只挑一个最重要的问题修改。
  4. 立刻做一道相似题或再演一次，检查是否真的改好。

做到什么算完成

第二次尝试已经使用了新方法，而且结果确实更好。

注意

“做得不好”“继续努力”不是有效反馈。反馈要说清楚错在哪一步、下一次改什么。

来源定位《学习之道》合集 TXT，第 4815、9150 行（直接反馈与模型纠错）
第 7 章

用项目和复盘把知识变成能力

3 / 3 条

最后不要再囤教程。用一个小项目检验自己是否真的会做，再通过每日复盘和每周检查持续改进。

1

每天花 5 分钟回答四个问题

#
核心动作每日每日复盘
说人话

学过、做过，不一定就有收获。每天用 5 分钟回想并写下来，才能把经历变成下一次可用的经验。

照着回答

  1. 今天我实际完成了什么？
  2. 哪个判断有效，证据是什么？
  3. 哪个地方卡住，真正原因是什么？
  4. 明天遇到同类情境，我先做什么？

做到什么算完成

最后写出一句具体规则：“如果下次遇到______，我就先______。”

注意

不要写成流水账。只记录对下一次行动有帮助的判断。

2

做一个一周内能完成的小项目

#
核心动作今天就做小项目
说人话

停止继续收藏教程。用一个一周内能交付的小项目，检查自己能不能把知识真正用出来。

照着做

  1. 选择一个真实使用者，哪怕只是朋友或未来的自己。
  2. 定义一周内能完成的最小成果。
  3. 先动手，遇到问题再定向补知识。
  4. 把成果交给别人使用或评价。
  5. 根据反馈至少修改一次。

示例

学统计时，用一份公开数据回答一个实际问题，并做成一页图文结论，而不只是继续看课程。

做到什么算完成

项目已经交给一个真实的人看过，并根据反馈完成了一次修改。

来源定位《学习之道》合集 TXT，第 7727、8253、9150 行（项目学习、应用与纠错）
3

每周检查：能否回想、判断、应用和改错

#
进阶动作每周每周检查
说人话

学习时间长，不代表学得好。每周只检查四件事：能不能想起来、选对方法、实际用出来，以及少犯同样的错。

每周检查表

检查什么 问自己
回想 不看资料，能答对多少核心问题？
判断 面对混合题，能选对方法吗？
应用 本周做出了什么可检查的成果？
改错 同一种错误比上周少了吗？

照着做

  1. 给四项各打 1～5 分。
  2. 只选最低的一项，作为下周重点。
  3. 把它改写成一个可检查的目标。

做到什么算完成

下周只有一个明确改进重点，而不是同时推翻整套学习安排。
